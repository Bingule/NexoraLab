# CV Kinetics on AimatraLab

The browser workspace is migrated from the same pinned public upstream revision recorded in `vendor/tmccdb/UPSTREAM.json`. Scientific modules retain their upstream bytes. It runs on AimatraLab without requesting the former website at runtime. Desktop source and license generation are not imported.

The online version has missing features and updates compared with the more complete offline application. Both language versions state this limitation. The tool registry lists 17 historical offline versions, with 19 Windows/macOS packages in total. The current Windows version is 2.1.7; macOS packages are historical 1.0.0 builds.

`offlineDownloadUnavailable: true` requires an empty `download` URL. Cards and the detail page show a disabled offline-download control. There is no public CV download redirect. Version history remains visible. Windows activation continues to be issued manually by the developer; the original distributables are not rebuilt or altered.

Offline ZIPs are archived as draft releases in the existing private desktop repository. No package, desktop source, issuer tool, key or customer license is committed to this website. The private archive includes SHA-256 checksums. Five early packages include third-party dependency source maps; these remain private archival originals and need review before future public distribution.

Only the browser workspace is included in the website. Browser-delivered JavaScript remains inspectable by visitors. Repository privacy alone does not conceal code already delivered by a web application.

The registry preview shows the migrated browser tool using synthetic demonstration data, not experimental measurements.
