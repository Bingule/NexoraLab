# AimatraLab 第一版实施计划

依据用户提供的完整需求直接实施，保持独立软件仓库，只消费 JSON 元数据。

1. 建立 Next.js + TypeScript 静态站点。使用普通 CSS，减少依赖；不引入后端、数据库、账户或计算服务。
2. 定义 manifest 类型和校验：唯一 slug、有效类别与软件类型、安全链接、可选截图与版本记录。先测试关键校验，再实现注册表。
3. 建立共享导航、工具卡片、科学示意图；完成首页、目录、Online Lab、Research、About、静态生成的工具详情和 `/lab/[id]` 演示入口。
4. 添加五份明确标记 demo 的元数据、可替换 SVG 品牌图标和用户原始照片。无真实 URL 的下载与外链按钮不展示。
5. 编写 manifest 模板、发布约定、中文 README 和 GitHub Pages Actions。只准备部署，不创建远程仓库。
6. 运行元数据测试、TypeScript、静态构建；浏览器检查所有路由、搜索筛选、空结果、移动导航、桌面和手机布局；检查静态内部链接和资源。

视觉：依据用户反馈改为浅灰白底、黑灰文字、少量深蓝强调、无渐变的晶格线稿和紧凑卡片。英文网站内容来自用户 brief；中文使用说明。示意图不作为真实软件截图或科学计算结果。
