# AimatraLab 本轮实现

保留视觉、静态部署和独立软件项目模式。首页顺序为 Hero → Featured Tools → Online Lab → Research → Founder → Latest Updates。

1. 注册表增加可选 `release`、`web` 和 `zh` 字段，旧清单继续兼容。
2. 手动 `npm run register -- <项目目录或清单路径>` 校验清单，复制明确声明的截图与网页构建目录；不编译软件、不创建仓库、不自动发布 Release。更新已有工具需要 `--replace`，先支持 `--dry-run`。
3. 在线工具以独立静态应用嵌入通用工作区，网站仅保存发布产物。用科学单位换算器验证真实可运行、可下载的发布路径；现有科研项目保持原位置。
4. 截图、版本、在线、下载、Release 链接由元数据驱动。未发布条目明确标注规划中，最新动态仅展示实际发布。
5. 中文/英文切换使用一个轻量客户端上下文；静态页默认英文，加载后恢复用户手动选择；首次访问保持英文。工具名称保留原名，中文元数据可选，缺失时回退英文。
6. 验证清单、导入（含失败不修改）、单位换算、静态构建、链接、双语切换和手机布局，再发布 GitHub Pages。
